# 图像数据增强课堂教学案例

本案例使用一张施工现场图片，通过 OpenCV、NumPy 和 Matplotlib 展示常见图像数据增强方法。运行程序后，可以同时看到原图、单项增强和多增强组合的效果。

## 1. 教学目标

通过本案例，学生可以：

- 区分几何增强和像素增强；
- 理解翻转、旋转、亮度、模糊和噪声的基本实现；
- 掌握像素类型转换、范围裁剪和随机种子的作用；
- 理解多种增强操作组成的数据增强流水线；
- 将数据增强方法与真实工程拍摄条件联系起来。

## 2. 数据增强与工程场景

| 数据增强 | 模拟的工程场景 | 难度 |
| --- | --- | ---: |
| 水平翻转 | 不同拍摄方向 | ★ |
| 旋转 | 相机倾斜、手持拍摄 | ★ |
| 亮度变化 | 阴天、强光、弱光 | ★ |
| 高斯模糊 | 相机失焦、轻微运动模糊 | ★ |
| 添加噪声 | 低质量摄像头、复杂环境 | ★★ |
| 多增强组合 | 多种不利拍摄条件同时出现 | ★★ |

## 8. 各增强方法原理

### 8.1 水平翻转

核心代码：

```python
flipped = cv2.flip(image, 1)
```

`cv2.flip()` 的第二个参数表示翻转方向：

- `1`：水平翻转；
- `0`：垂直翻转；
- `-1`：水平和垂直同时翻转。

水平翻转可以模拟目标从相反方向进入镜头，但不改变图像尺寸和颜色。

### 8.2 旋转

案例以图像中心为旋转中心，执行顺时针 15° 旋转：

```python
matrix = cv2.getRotationMatrix2D(center, -15.0, 1.0)
rotated = cv2.warpAffine(image, matrix, (width, height))
```

OpenCV 中正角度表示逆时针，因此代码使用 `-15.0` 表示顺时针 15°。

输出画布保持原图尺寸，所以：

- 超出画布的内容会被裁剪；
- 旋转后没有图像内容的位置会出现黑边。

这正好模拟相机倾斜或手持拍摄时的几何变化。

### 8.3 亮度变化

案例使用乘法调整亮度：

```python
adjusted = image.astype(np.float32) * factor
result = np.clip(adjusted, 0, 255).astype(np.uint8)
```

默认参数：

- `factor = 0.55`：降低亮度，模拟阴天或弱光；
- `factor = 1.45`：提高亮度，模拟强光。

先转换为 `float32`，是为了避免 `uint8` 运算发生溢出。计算后必须用 `np.clip()` 将像素裁剪到 `[0, 255]`，最后再转换回 `uint8`。

### 8.4 高斯模糊

核心代码：

```python
blurred = cv2.GaussianBlur(image, (7, 7), 0)
```

高斯模糊会让相邻像素进行加权平均，使边缘和纹理变得平滑，可模拟相机失焦。

卷积核大小必须是正奇数，例如：

- `3×3`：轻微模糊；
- `7×7`：中等模糊；
- `11×11`：更强模糊。

严格来说，运动模糊通常具有方向性；本案例使用高斯模糊重点演示失焦和平滑效果。

### 8.5 添加高斯噪声

程序使用 NumPy 生成高斯分布随机噪声：

```python
generator = np.random.default_rng(42)
noise = generator.normal(0.0, 20.0, image.shape)
noisy = image.astype(np.float32) + noise
result = np.clip(noisy, 0, 255).astype(np.uint8)
```

默认参数：

- 均值 `0`：噪声整体不偏向变亮或变暗；
- 标准差 `20`：控制噪声强度；
- 随机种子 `42`：保证每次运行结果一致。

固定随机种子有利于课堂复现和自动验证。改变种子后，噪声分布仍符合相同规律，但具体噪声点会变化。

### 8.6 多增强组合

组合增强的固定顺序为：

```text
顺时针旋转 15° → 亮度降低 → 高斯模糊 → 添加高斯噪声
```

程序复用各单项增强函数：

```python
result = rotate_image(image, angle_degrees=15.0)
result = adjust_brightness(result, factor=0.55)
result = gaussian_blur(result, kernel_size=7)
result = add_gaussian_noise(result, stddev=20.0, seed=42)
```

多增强组合用于模拟拍摄方向倾斜、环境较暗、相机失焦和传感器噪声同时出现的情况。

增强顺序会影响最终结果。例如，“先加噪声再模糊”会同时平滑图像内容和噪声，而“先模糊再加噪声”会保留更明显的噪声点。

## 9. 参数调节实验

1. 将旋转角度从 `15.0` 改为 `30.0`，观察裁剪和黑边变化。
2. 将弱光系数从 `0.55` 改为 `0.30`，比较暗部细节损失。
3. 将强光系数从 `1.45` 改为 `2.00`，观察高亮区域是否饱和。
4. 将高斯核从 `7` 改为 `3` 或 `11`，比较模糊程度。
5. 将噪声标准差从 `20.0` 改为 `5.0` 和 `40.0`，比较图像质量。
6. 修改随机种子，观察噪声点位置的变化。
7. 交换“模糊”和“加噪声”的顺序，比较组合增强结果。

每次修改参数后重新运行：

```bash
python main.py
```

## 10. 训练集、验证集和测试集

在机器学习工程中，通常：

- **训练集**：可以使用随机数据增强，提高模型对不同拍摄条件的适应能力；
- **验证集**：通常只执行确定性的尺寸调整和归一化，用于稳定比较不同模型；
- **测试集**：通常保持原始分布，用于评价模型在真实数据上的表现。

如果验证集和测试集每次都随机变化，评价结果也会随机变化，不利于公平比较。

数据增强还必须符合任务语义。例如，交通标志中的左右方向可能有不同含义，此时不能随意水平翻转。
