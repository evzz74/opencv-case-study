# 数据增强课堂教学案例设计

## 1. 背景与目标

本案例使用施工现场图片 `数据增强/datsset/image/001.png`，通过直观的单项增强和组合增强，帮助学生理解数据增强如何模拟真实工程中的拍摄条件变化。

案例面向计算机视觉入门课堂，重点不是调用高度封装的数据增强框架，而是使用 OpenCV 和 NumPy 展示每种操作的基本原理、参数及图像变化。

完成后，学生应能够：

1. 理解几何增强与像素增强的区别；
2. 使用 OpenCV 完成水平翻转、旋转和高斯模糊；
3. 使用 NumPy 完成亮度调整和高斯噪声叠加；
4. 理解像素计算中的类型转换、范围裁剪和随机种子；
5. 将多个增强操作串联成简单的数据增强流水线；
6. 结合工程场景判断增强方法是否合理。

## 2. 技术方案

采用 Python 单文件教学脚本，主要依赖：

- OpenCV：图像读取、保存、翻转、旋转和高斯模糊；
- NumPy：亮度计算、高斯噪声生成、像素范围裁剪；
- Matplotlib：生成带中文标题的课堂对比总图。

不使用 Albumentations 等高度封装的专业增强库，以便学生直接观察每种增强操作的实现过程。所有文件均使用 UTF-8 编码。

## 4. 程序组成

`数据增强/main.py` 保持为可直接运行的单文件案例，包含以下部分：

1. `read_image()`：使用 NumPy 字节流和 `cv2.imdecode()` 读取图片，支持 Windows 中文路径；
2. `write_image()`：使用 `cv2.imencode()` 保存图片，支持 Windows 中文路径；
3. `horizontal_flip()`：水平翻转；
4. `rotate_image()`：按指定角度旋转并保持原图尺寸；
5. `adjust_brightness()`：按亮度系数调整像素值；
6. `gaussian_blur()`：执行高斯模糊；
7. `add_gaussian_noise()`：添加可复现的高斯噪声；
8. `combined_augmentation()`：复用单项函数完成多增强组合；
9. `create_comparison_figure()`：生成 2×4 教学对比图；
10. `main()`：串联读取、增强、校验、保存和展示流程。

每个增强函数只负责一种操作，输入和输出均为 NumPy 图像数组，便于单独讲解、修改和验证。

## 5. 增强操作设计

| 操作 | 实现方式 | 默认参数 | 模拟的工程场景 | 难度 |
| --- | --- | --- | --- | ---: |
| 水平翻转 | `cv2.flip(image, 1)` | 水平翻转 | 不同拍摄方向 | ★ |
| 旋转 | 仿射变换 | 顺时针 15° | 相机倾斜、手持拍摄 | ★ |
| 亮度降低 | 像素线性变换 | 系数 0.55 | 阴天、弱光 | ★ |
| 亮度提高 | 像素线性变换 | 系数 1.45 | 强光 | ★ |
| 高斯模糊 | `cv2.GaussianBlur()` | 7×7 卷积核 | 相机失焦 | ★ |
| 添加噪声 | NumPy 高斯分布 | 均值 0、标准差 20 | 低质量摄像头、复杂环境 | ★★ |
| 多增强组合 | 依次复用单项函数 | 旋转→亮度降低→模糊→噪声 | 多种不利条件同时出现 | ★★ |

### 5.1 水平翻转

水平翻转改变图像左右方向，但不改变尺寸、颜色和像素类型，用于模拟目标从不同方向进入镜头的情况。

### 5.2 旋转

以图像中心为旋转中心，使用仿射变换执行顺时针 15° 旋转。输出画布保持原图尺寸，超出画布的内容被裁剪，新增空白区域使用黑色填充。

该现象用于说明几何变换可能改变边界内容。代码和 README 必须明确 OpenCV 角度正负方向的约定，避免“顺时针 15°”与实际结果不一致。

### 5.3 亮度变化

将图像转换为浮点数后乘以亮度系数：

- `0.55`：模拟弱光；
- `1.45`：模拟强光。

计算完成后，将像素值裁剪到 `[0, 255]`，再转换回 `uint8`，防止整数溢出或无效像素值。

### 5.4 高斯模糊

使用 7×7 的奇数卷积核执行高斯模糊，展示相机失焦造成的边缘和纹理信息损失。程序应允许教师通过函数参数修改卷积核大小。

### 5.5 高斯噪声

使用均值为 0、标准差为 20 的高斯分布生成噪声。噪声与浮点图像相加后执行范围裁剪，再转回 `uint8`。

默认随机种子固定，使每次运行生成相同结果，便于课堂讲解、学生复现和结果验证。函数仍接受种子参数，方便扩展随机实验。

### 5.6 多增强组合

组合增强顺序固定为：

```text
原图 → 顺时针旋转 15° → 亮度降低 → 高斯模糊 → 添加高斯噪声
```

组合函数复用单项增强函数，不重复实现底层逻辑。README 将提示学生思考不同执行顺序是否会产生不同结果。

## 6. 数据流

```text
读取原图
   │
   ├── 水平翻转
   ├── 顺时针旋转 15°
   ├── 亮度降低
   ├── 亮度提高
   ├── 高斯模糊
   ├── 添加高斯噪声
   └── 旋转 → 亮度降低 → 模糊 → 噪声
              │
              ↓
       结果尺寸与类型校验
              │
              ├── 保存单项结果
              └── 生成并保存 2×4 对比总图
```

所有增强结果应满足：

- 宽度和高度与原图一致；
- 通道数与原图一致；
- 数据类型为 `uint8`；
- 像素值位于 `[0, 255]`。

生成一张 2×4 对比总图：

```text
┌──────────┬──────────┬──────────┬──────────┐
│   原图   │ 水平翻转 │ 旋转 15° │ 亮度降低 │
├──────────┼──────────┼──────────┼──────────┤
│ 亮度提高 │ 高斯模糊 │ 高斯噪声 │ 多增强组合│
└──────────┴──────────┴──────────┴──────────┘
```

显示要求：

- OpenCV 的 BGR 图像必须转换为 RGB 后交给 Matplotlib；
- 每幅子图使用中文标题；
- 关闭坐标轴；
- 使用紧凑布局，避免标题重叠；
- 总图以适合课件展示的分辨率保存；
- 默认显示窗口，同时支持通过顶部配置关闭交互显示，以适应无图形界面的运行环境。

## 9. 错误处理

程序需要处理以下异常：

- 输入文件不存在：输出包含具体路径的中文错误；
- 图像字节为空或解码失败：说明无法读取输入图像；
- 旋转角度或亮度系数不是有限数字：抛出清晰的参数错误；
- 高斯卷积核不是正奇数：拒绝执行并说明要求；
- 噪声标准差为负数：拒绝执行；
- 图像数组为空、维度错误或类型不受支持：拒绝执行；
- 输出编码或写入失败：输出具体目标路径。

`main()` 捕获预期异常，向标准错误流输出中文错误，并返回非零退出码。成功运行返回 0。

## 10. 验证方案

本案例采用轻量但完整的验证方式：

1. 运行 `python main.py`，确认退出码为 0；
2. 检查 `output/` 中 8 张单图和 1 张对比总图均已生成；
3. 检查每个增强结果与原图尺寸、通道数和数据类型一致；
4. 检查所有输出像素值位于 `[0, 255]`；
5. 使用相同随机种子调用噪声函数两次，确认结果完全一致；
6. 使用不同随机种子调用噪声函数，确认结果存在差异；
7. 重新读取所有输出 PNG，确认能够正常解码；
8. 人工查看对比总图，确认标题、颜色、布局和增强效果正确；
9. 检查 README 中的运行命令和输出文件名与实际程序一致。

该案例不引入复杂的测试工程结构；核心验证通过函数级断言和脚本端到端运行完成，避免让测试框架分散入门课堂的注意力。

- 学生运行一个命令即可生成全部结果；

- 每种增强均有独立函数、中文注释、参数说明和工程场景解释；
